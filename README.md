# 📦 Inventory Management System

A lightweight, console-based inventory management application designed to track warehouse stock, update product pricing, and manage item quantities efficiently.

## 🎯 Project Overview
Effective stock tracking is critical for any storage operation. This project provides a streamlined solution to monitor product availability and dynamic pricing without the overhead of a heavy database. It handles data persistence locally, ensuring that all stock adjustments and price updates are safely recorded and easily retrievable.

## ✨ Features
- **Stock Tracking:** Real-time monitoring of available product quantities.
- **Price Management:** Update product prices dynamically directly from the interface.
- **Inventory Logging:** Add new products to the warehouse or remove discontinued items.
- **Persistent Storage:** Saves all inventory data using file handling operations so no records are lost between sessions.

## 🛠️ Tech Stack
- **Language:** C 
- **Core Concepts:** Data Structures, File I/O, CRUD Operations
